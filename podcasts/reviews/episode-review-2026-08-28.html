Answers API hit its usage ceiling mid-script

The script generation process has a segment called script/brave-answers that draws from Brave's Answers API. During this run, that API returned a 402 error with an "Usage limit exceeded" response. The pipeline switched to web snippets for the remainder of the script and continued.

This is a graceful fallback—the episode still aired with sourced material—but it represents a hard boundary. When the budget exhausts, the pipeline has no option to wait or retry at a different time. It downgrades and moves forward.

Citation matching broke down in the deep dives

The roundup section matched 13 of 15 citations to their sources. The deep dive section matched 2 of 3. The three deep dive stories were from APTN News, Forbes Innovation, and Vancouver Sun; the data does not show which source failed to align or why.

This gap is small in volume but structural. Roundup citations (news briefs) traced back reliably. Longer-form analysis did not. The pipeline will need to examine whether the matching logic scales to deeper reporting or if these segments need different handling.

The audio render began using Gemini's multi-speaker text-to-speech for the welcome section. The connection timed out after 120 seconds. The pipeline fell back to OpenAI for that section and all following sections and credits.

The episode is therefore a seam: welcome came from one voice provider, the body and outro from another. The video file is 50.2 MB and 17.7 minutes long. The audio is 16.2 MB and the same 17.7 minutes. Listeners heard both, but not from a single synthesis engine.
